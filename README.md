Projeto com enfase em media query

Neste projeto, foi utilizado o Figma para uso de referência, medidas e resoluções da página. Utilizando HTML e CSS foi construído a página baseado nas medidas dadas. Com o media query foi possível fazer com que funcionasse em diferentes resoluções de maneira fluída e sem alterar ou distorcer os elementos.
